# Serial App

## Overview
Serial App is a project designed to handle serial communication between devices. It provides an easy-to-use interface for sending and receiving data over serial ports.

## Features
- Support for multiple serial ports.
- Configurable baud rate, parity, and stop bits.
- Real-time data monitoring.
- Logging of serial communication.

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/serial_app.git
    ```
2. Navigate to the project directory:
    ```bash
    cd serial_app
    ```
3. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Usage
1. Run the application:
    ```bash
    python main.py
    ```
2. Configure the serial port settings as needed.
3. Start sending and receiving data.
